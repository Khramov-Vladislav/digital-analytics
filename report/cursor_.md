Проект представляет собой веб-приложение «Генератор резюме», пред-
назначенное для автоматического создания резюме в формате pdf на основе
данных, введённых пользователем через веб-форму. Информация от поль-
зователя: основные персональные данные, навыки, образование и опыт ра-
боты. Также приложение будет поддерживать загрузку фотографии поль-
зователя и выбор одного из нескольких шаблонов оформления резюме. По-
сле заполнения формы система будет давать предварительный просмотр
документа в браузере, позволяя пользователю проверить корректность дан-
ных и внешний вид перед генерацией итогового файла. После генерации pdf
будет происходить отправка готового файла пользователю для скачивания.
Backend-часть приложения будет реализована на языке Go с использова-
нием стандартного http-сервера и шаблонов html
Вводимые пользователем данные
Пользователь заполняет следующие данные:
ФИО
Контактные данные (телефон, email, город)
Краткая информация о себе
Образование (учебное заведение, специальность, годы обучения)
Опыт работы (компания, должность, период, обязанности)
Навыки
Дополнительная информация (языки, сертификаты и т.д.)
Фотография

Ограничения на данные
Текстовые поля: до 1000 символов для больших блоков, до 100 символов для коротких полей.
Поддерживаемые языки: русский и английский (символьная кодировка UTF-8).

Ограничения на фотографию
Форматы: JPG, JPEG, PNG
Максимальный размер файла: 5 МБ
Минимальное разрешение: 400×400 px
Соотношение сторон: любое 

Шрифты и оформление
Используются стандартные веб-безопасные шрифты (Arial, Times New Roman)
В PDF применяются встроенные шрифты для корректного отображения на любых устройствах (Arial, Times New Roman)
Размеры шрифтов фиксированы шаблоном, пользователь их не меняет.

Предварительный внешний вид приложения
Интерфейс состоит из двух областей:
слева — форма ввода данных
справа — динамический предпросмотр резюме
Предпросмотр обновляется автоматически после изменения полей, чтобы пользователь сразу видел результат.

Шаблоны резюме
Планируется реализовать несколько шаблонов:
Классический — чёрно-белая цветовая схема, традиционная структура блоков.
Современный — использование цветовых акцентов, визуальных разделителей, иконок навыков.
