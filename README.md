# Генератор резюме (Go + HTML templates)

Веб‑приложение для генерации резюме в PDF.

Что делает приложение:

- принимает данные резюме через веб-форму (включая фото)
- показывает живой предпросмотр в браузере
- генерирует PDF и отправляет файл на скачивание
- поддерживает несколько шаблонов оформления

## Требования

- Go 1.22+
- Установленный Chrome/Chromium (нужен для генерации PDF).  
  Если браузер не находится автоматически, задайте `CHROME_BIN` (путь к бинарнику).

## Запуск

```bash
go mod tidy
go run ./cmd/server
```

Откройте в браузере `http://127.0.0.1:8080`.
