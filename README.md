# Генератор резюме (Go + HTML templates)

Веб‑приложение, которое:

- принимает данные резюме через веб‑форму (включая фото)
- показывает **живой предпросмотр** в браузере
- генерирует **PDF** (через headless Chrome `PrintToPDF`) и отдаёт файл на скачивание
- поддерживает 4 шаблона: **classic**, **modern**, **sidebar**, **elegant**

## Требования

- Go 1.22+
- Установленный Chrome/Chromium (нужен для генерации PDF)
  - если браузер не находится автоматически, задайте `CHROME_BIN` (путь к бинарнику)

## Запуск

```bash
go mod tidy
go run ./cmd/server
```

Откройте в браузере `http://127.0.0.1:8080`.

## Ограничения

- **Короткие поля**: до 100 символов
- **Большие текстовые блоки**: до 1000 символов
- **Фото**: JPG/JPEG/PNG, до 5 МБ, мин. 400×400 px

## Тестовый пример

В UI есть кнопка **«Заполнить пример»**. Данные берутся из файла `cmd/server/web/static/example.json` — можно менять его под себя.

Также есть 2 файла для проверки ограничений (RU/EN):

- `cmd/server/web/static/example_ru_limits.json`
- `cmd/server/web/static/example_en_limits.json`
